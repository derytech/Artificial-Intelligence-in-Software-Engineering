# AI: Dynamic Web Lab Generation for Core CSS Concepts

## Overview

This task demonstrates the use of AI-assisted development to create interactive web labs for learning core CSS concepts.

The project contains two interactive playgrounds:

1. CSS Box Model and Display Property Playground
2. CSS Flexbox and Grid Playground

The development process used sequential AI prompting. The first prompt generated the initial Box Model playground, the second prompt refined it with individual side controls, and the third prompt generated the Flexbox and Grid playground.

## Files

### `box-model-initial.html`

The initial CSS Box Model playground.

It demonstrates:

- Content, padding, border, and margin areas
- Box 1 and Box 2
- Padding control
- Margin control
- Border-width control
- Width control
- Display property controls
- Real-time JavaScript updates

### `box-model-refined.html`

The refined Box Model playground.

It adds individual controls for:

- Margin top, right, bottom, and left
- Padding top, right, bottom, and left
- Border top, right, bottom, and left
- Border radius

Each control updates Box 1 in real time.

### `flexbox-grid-playground.html`

An interactive playground for CSS Flexbox and Grid.

It demonstrates:

- Block, Flex, and Grid display modes
- Flex direction
- Justify content
- Align items
- Grid template columns
- Real-time layout changes
- Multiple child elements

## AI Prompting Process

### Prompt 1

Generated the initial CSS Box Model and display property playground.

### Prompt 2

Refined the Box Model playground by adding individual controls for each side of the margin, padding, and border, together with corner radius control.

### Prompt 3

Generated an interactive Flexbox and Grid playground with controls for changing container layout properties.

## Learning Outcome

The interactive playgrounds make it possible to experiment with CSS properties and immediately observe their effects on the layout. This provides a practical way to understand the CSS Box Model, display properties, Flexbox, and Grid.

The project also demonstrates how sequential AI prompting can be used to generate an initial solution and then refine it based on additional requirements.
